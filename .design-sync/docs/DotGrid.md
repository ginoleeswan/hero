A full-bleed dotted-grid texture (SVG pattern) that fills its positioned parent via `StyleSheet.absoluteFill`. A quiet decorative layer for dark surfaces. Tune `color`, `spacing`, and dot `radius`.

```tsx
<View style={{ position: 'relative' }}>
  <DotGrid color="rgba(245,235,220,0.07)" spacing={24} />
</View>
```
