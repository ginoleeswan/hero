A single loading placeholder block that breathes (a calm unison opacity pulse). Compose several to sketch a screen's layout while data loads. `height` is required; `width` defaults to `'100%'`; `borderRadius` rounds the corners; `dark` tunes it for dark surfaces.

```tsx
<SkeletonBlock width={200} height={20} borderRadius={6} />
```
