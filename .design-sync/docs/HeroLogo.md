The Mythique wordmark lockup — the masked flame glyph (SVG) next to the lowercase "mythique" display wordmark. Scale with `iconSize`/`fontSize`, recolour with `color` (and optionally a separate `iconColor`), or drop the text with `iconOnly` for a compact mark.

```tsx
<HeroLogo iconSize={28} fontSize={24} />
<HeroLogo iconOnly />
```
